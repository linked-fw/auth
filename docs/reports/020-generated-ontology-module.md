# 020 — Generated ontology module

## Why

Report 019 left auth's own ontology as a hand-written module with an aggregated `auth` object,
while every vocabulary package now generates its accessor modules from its Turtle (cli report
027). The shapes also took `xsd.dateTime` from `@_linked/core/ontologies/xsd`, which is internal
to core.

## What changed

- `package.json`: `"linkedOntologies": {"auth": {"namespace": "https://linked.cm/ont/auth/"}}`
  (data defaults to `auth.ttl`); `@_linked/cli` (dev) ^1.57.0 → ^1.57.1; lockfile refreshed.
- `src/ontologies/auth.ts`, `auth.data.ts` (new), `auth.register.ts`: written by
  `linked generate-ontology` ("auth: 37 terms from src/data/auth.ttl"). The 37 terms are exactly
  the hand-written module's; `_self` is now `_ontologyResource`, and `ns`, `dataFiles`, `loadData`
  live in `auth.data`.
- Shapes (`AuthCredential`, `Authentication`, `IdentityToken`, `Password`, `RefreshToken`,
  `UsedOAuthNonce`): `import * as auth from '../ontologies/auth.js'`; `xsd` from
  `import * as xsd from '@_linked/xsd/ontologies/xsd'` (already a dependency, ^1.4.0).
- `utils/migrateNamespace.ts`: `ns` from `auth.data.js`.
- `backend.ts`: dropped the unused `auth` import (the only `auth.` there is a local variable).
- `test/shapes.test.mjs`: the module namespace and `ns` from `auth.data.js`.
- Changeset (minor): the object is gone; use `import * as auth`.

Consumers of the old object outside auth: none. A grep of CN (`src`, `packages`, `tests`,
`scripts`), every `packages-local/*` checkout, app-template and webid-email for
`@_linked/auth/ontologies/auth` finds nothing.

## PR

### Summary

Generates auth's ontology module from its Turtle and drops the aggregated `auth` object; the
shapes take `xsd` from `@_linked/xsd`.

### Changes

- `linkedOntologies` in `package.json`; `src/ontologies/auth.ts`, `auth.data.ts`,
  `auth.register.ts` generated by `linked generate-ontology` (cli ^1.57.1). Same 37 terms;
  `_self` → `_ontologyResource`; `ns`/`dataFiles`/`loadData` in `auth.data`.
- Auth's consumers rewritten to `import * as auth`; `migrateNamespace` and the shapes test read
  `ns` from `auth.data`; an unused import removed from `backend.ts`.
- `xsd` from `@_linked/xsd/ontologies/xsd` instead of core's internal module.
- Minor changeset listing the breaking change.
